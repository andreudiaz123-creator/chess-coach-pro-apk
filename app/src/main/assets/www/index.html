🔥 Momentos Críticos y Oportunidades

Metodología documentada de precisión y umbrales: Para cada jugada se transforma la evaluación antes ($E_{\text{antes}}$) y después ($E_{\text{después}}$) en probabilidad esperada de victoria mediante $W(p) = 50 + 50 \cdot \left(\frac{2}{1 + e^{-0.368 \cdot p}} - 1\right)$, donde $p$ es la evaluación en peones desde la perspectiva del jugador que mueve. La precisión individual de cada movimiento se calcula como $\text{Acc}_i = \max(0, 103.1668 \cdot e^{-0.04354 \cdot \Delta W_i} - 3.1669)$ y la precisión global es la media ponderada de todas las jugadas del jugador. Esta fórmula es transparente, reproducible y propia de Chess Coach Pro (no pretende replicar fórmulas propietarias cerradas de terceros).

📱 Usar Chess Coach Pro como App en Android (.APK / PWA)

Dos formas reales de instalar la aplicación en tu teléfono o tableta Android

Opción 1: Instalar directamente desde Chrome en Android (Sin compilar)

Inmediato

Esta aplicación ya incluye manifiesto Progressive Web App (PWA) y modo pantalla completa para Android:

  1. Abre el archivo chess_coach_pro.html (o súbelo gratis a GitHub Pages / Netlify / Vercel) desde Google Chrome en tu móvil Android.
  2. Toca el menú de Chrome (⋮ arriba a la derecha) y selecciona «Instalar aplicación» o «Añadir a pantalla de inicio».
  3. Se creará el icono de Chess Coach Pro en tu cajón de aplicaciones y se abrirá a pantalla completa igual que un APK nativo.

Opción 2: Generar el instalador .APK con el paquete Android incluido

Android Studio / GitHub Actions

Descarga el archivo adjunto chess_coach_pro_android_apk_project.zip que he generado junto a esta aplicación. Incluye el proyecto Android nativo (MainActivity.java con WebView acelerado por hardware, AndroidManifest.xml, iconos adaptativos y configuración Gradle):

  • En la nube sin instalar nada en tu PC (GitHub Actions): Sube el contenido del ZIP a un repositorio de GitHub; el flujo incluido (.github/workflows/build-apk.yml) compila automáticamente el archivo ChessCoachPro-debug.apk listo para descargar en la pestaña Actions → Artifacts.
  • En tu PC con Android Studio: Descomprime el ZIP, abre la carpeta en Android Studio y pulsa Build → Build Bundle(s) / APK(s) → Build APK(s), o ejecuta ./gradlew assembleDebug.
